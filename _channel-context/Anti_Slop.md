# Writing patterns to avoid (summary)

This summarises the "Anti Slop" doc in the Battlefield project. Read the full doc there for every variant. Run two passes on every script before handing it over.

## Pass 1: zero tolerance
- Negative parallelism in any form ("It is not X, it is Y", "Not X, but Y", "X was never A, it was B"). State the positive claim directly. Contrasts between different subjects, and real changes of state, are fine.
- Triple countdowns ("Not X. Not Y. Just Z.").
- More than one rule-of-three per section. Decorative three-item lists.
- The same sentence opener three or more times in a row.
- False ranges ("from X to Y" with no real middle).
- Tacked-on -ing phrases ("...highlighting the importance of").
- Teaser transitions ("Here's the thing", "Here's where it gets interesting").
- "Let's dive in" / "Let's break this down".
- Vague attributions ("Experts say", "Research shows"). Name the source or cut the claim.
- Invented concept labels, fake balance ("Despite these challenges..."), filler ("It is worth noting").
- "The real story is...", grandiose stakes, forced analogies ("Think of it like..."), "Imagine a world where...".
- Invented numbers, dates or timeframes. If the source has no number, use no number.
- Fancy metaphorical verbs where a literal verb works.
- Openers like "In a world where", "At its core", "Welcome to". Closers like "In conclusion", "Ultimately", "At the end of the day".

## Pass 2: avoid clustering
- Inflated words: pivotal, crucial, robust, tapestry, landscape, testament, delve, harness, leverage, showcase, underscore, quietly, deeply, fundamentally.
- Use "is" instead of "serves as", "stands as" or "represents".
- Vary sentence and paragraph length. Do not summarise, then restate, then summarise again.
- Few em dashes. No unicode arrows or curly quotes. No emoji.

## Where this conflicts with the channel style
The channel style guide wins. The user's own voice uses present-tense narration and "So, how did...? It starts with..." questions, and both are kept on purpose.
